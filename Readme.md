# Futuristic Classroom Visualizer

This project visualizes the evolution of classroom learning, contrasting how students of the past listened to classes with how students in the future might experience them. The theme centers on the transformation from traditional, passive listening to immersive, visually rich learning environments.

## Theme

**"From Chalkboards to Space Screens: Visualizing the Future of Learning"**

- **Past:** Students used to listen to classes in a traditional setting, focusing on the teacher and chalkboard, with limited visual aids.
- **Future:** Students experience classes through advanced visual screens projected in space, enabling them to visualize concepts in vivid detail and interact with lessons in new, engaging ways.

This project aims to depict this transition, highlighting the impact of technology on education and the enhanced ability of students to visualize and understand complex topics.

## How to Run

1. **Install Dependencies**
   - Make sure you have Python installed.
   - Install OpenCV:
     ```bash
     pip install opencv-python
     ```

2. **Usage**
   - Place your input image (e.g., `input.jpeg`) in the project directory.
   - Run the script:
     ```bash
     python lens.py --input input.jpeg --output output.jpeg --debug
     ```
   - The output image will be saved as `output.jpeg`.

## Project File
- `lens.py`: Main script for visualizing the classroom transformation.
